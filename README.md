# Lueur · Perfumaria

Landing page conceitual de uma casa de perfumes (projeto de portfólio; não é uma loja real e não processa pagamentos).

Site estático: `index.html` + `assets/`. Sem build.

## Publicar na Vercel
- Pelo Git: importe este repositório em vercel.com/new (Framework: Other, sem build command, output: raiz).
- Pela CLI: `npx vercel --prod` dentro desta pasta.
